# EVENTHUB - Sistem Pendaftaran Workshop Informatika

Proyek web front-end interaktif untuk pendaftaran workshop informatika. Dibuat menggunakan HTML5, CSS3, Bootstrap 5, dan JavaScript dasar.

## Alur Dasar HTTP Request / Response:
Browser (Client) ---> HTTP Request ---> Web Server (misal: Apache / Live Server)
Browser <--- HTTP Response (HTML/CSS/JS) <--- Web Server

1. **Browser** mengirimkan permintaan HTTP (Request) ke Web Server.
2. **Web Server** memproses dan merespons dengan mengirimkan berkas statis (HTML, CSS, JS).
3. **Browser** merender konten HTML, menerapkan gaya CSS, dan menjalankan eksekusi JavaScript untuk fungsionalitas interaktif.

## Struktur Folder Proyek:
- `css/style.css` : File stylesheet eksternal kustom.
- `js/script.js`  : Logika manipulasi DOM dan penanganan event form pendaftaran.
- `images/`       : Direktori aset gambar.
- `index.html`    : Halaman web utama berbasis Bootstrap 5 & tag semantik HTML5.
